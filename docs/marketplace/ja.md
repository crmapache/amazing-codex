# Amazing Codex GUI

**JetBrains IDE の中で、OpenAI Codex をそのままチャットパネルに。** ターミナルの流れる出力ではなく
カードで、パスを打ち込むのではなくファイルを指し示して、しかもコードのすぐ隣で。

動かしているのは、すでにお使いのマシンに入っている Codex CLI そのものです。ChatGPT への
サインインや API キー、モデル、設定、MCP サーバー、スキル、そしてご自身のカスタムプロンプトまで、
そっくりそのまま使えます。間に立つプロキシもなければ、こちらのアカウント登録もありません。

## これを選ぶ理由

- **一度書けば、あとは代わりに実行してくれる一連の作業。** シナリオでは、実装・レビュー・修正・
  テスト実行のような、それぞれが独立した Codex スレッドであるいくつかのカードを、何度でも周回
  できる段階に並べ、一本の主スレッドがそれらを歩きながら、各カードが見つけたことを判定します。
  ボタンひとつで一つ実行する、三つのチケットに対して同時に三つ実行する、あるいは平日の朝九時に、
  あらかじめ質問への回答を用意したうえで時刻指定で実行する、といったことができます。作業内容を
  一文で説明すれば、Codex がプロジェクトを読んでフォームを書き上げます。
- **「はい」ボタンだけでなく、パネルまるごとをスマートフォンから。** 承認やプランに答える、
  閉じているプロジェクトを開く、昨日のチャットを読む、分岐する、モデルと思考の強さを変える、
  アカウントを切り替える、シナリオの実行を見守り、詰まりを解消する。既定ではオフ、QR コードで
  ペアリング、一言も読めない中継サーバーを介して端末間で暗号化、解除はワンタップ。
- **複数の Codex アカウントを、ワンクリックで切り替え。** 一台のマシンで、どちらもサイン
  アウトすることなく仕事用とプライベート用を両立できます。それぞれが自分のサインインを保った
  まま、履歴・設定・スキルは共有されます。行ごとにそのアカウントの上限の残りが表示され、Select
  を押せば開いているすべてのチャットがそのアカウントへ移ります。
- **プロジェクトのすべての会話を横断検索。** 前方一致、誤字、語幹、引用符で囲んだフレーズに
  対応し、この会話だけでもすべての会話でも検索でき、そのままチャット内の該当メッセージへ
  ジャンプします。言葉で言い表せないときは、探しているものを説明すれば Codex が会話を読んで
  探してくれます。
- **していることがすべて画面に出る。** 所要時間つきのすべてのコマンド、実際の行番号が入った
  開いた状態の差分としての編集、消し込まれていくプラン、ウェブ検索、MCP ツール呼び出し、そして
  そのターンがトークンでいくらかかったか。リクエストの再試行や上限切れも、黙り込むのではなく、
  理由とカウントダウンをカードで示します。
- **誰かが代わりに答えることはなく、何も失われない。** 承認もプランも質問も、必要な
  だけ待ちます - 時間切れも自動継続もありません。パネルを畳んでも、プロジェクトを切り替えても
  会話は動き続け、ターンの最中に書いたメッセージは、そのターンに直接取り込まれるか、IDE が保持
  するキューで順番を待ちます。
- **Android Studio にも対応**、2026.1 以降のすべての JetBrains IDE で動きます。

## パネルにあるもの

- **ファイルは打つのではなく、指し示す。** ドラッグして落とす、`@` と打って選ぶ、スクリーン
  ショットや長いログをそのまま貼る - どれもチップになるので、打ち間違えようがありません。
- **コードは住所ごと渡る。** 行を選んで「Send to Amazing Codex GUI」。エージェントは文脈の
  ない断片ではなく、その周りにある本物のファイルを読みます。
- **パスはファイルを開く。** 会話のどこにあるパスでも - カードの見出し、回答、エラー、自分の
  メッセージのものでも - 指定された行でエディタにファイルが開き、編集を指すパスならその編集の
  場所が開きます。
- **回答のどの部分も取っ手になる。** 次のメッセージに引用する、その地点から会話を分岐する、
  チャットの上に最大三件までピン留めする、あるいは送信済みのメッセージを入力欄に戻して直して
  から再送する。
- **モデル・思考の強さ・承認モードは会話の途中で切り替わる**、タブごとに独立していて、再起動は
  不要です - 毎回確認する、自動、読み取りのみ、プラン、フルアクセスのいずれか。思考の強さの
  メニューには、選んだモデルが実際に持つ段階だけが並びます。
- **MCP サーバーとプラグイン**はそれぞれ専用の画面を持ち、どのサーバーが動いているか、どれが
  サインインを求めているか、どれが落ちていて、なぜかが分かります。
- **履歴** - このプロジェクトの過去の会話。ターミナルで始めたものも含み、末尾から開いて、
  必要に応じて過去へページをさかのぼれます。
- **Codex 自身のコマンド** - `/compact`、`/review`、`/init`、`/new`、そしてご自身のカスタム
  プロンプトとスキル - が入力欄の候補に出ます。
- **サイドの質問** は `/side` または `/btw` で。Codex の作業中に質問すると、答えは入力欄の
  上のカードに届き、会話には残りません。
- **Codex 自身の設定** を専用の画面で (`/config`)。config.toml の内容と各値の出どころを
  確認し、ワンクリックでプロジェクトを信頼できます。
- **`!` で自分のシェルのコマンドを実行**、その出力は次のメッセージと一緒に届き、ターンも
  承認も消費しません。
- **プロンプトの改善** - きらめきボタンが下書きを別の実行で書き直します。会話のコンテキスト
  は減らず、ボタンひとつで自分の言葉に戻せます。
- **音声入力** - ご自身の Deepgram キーで。ホットキーを押している間だけ有効で、エディタから
  でも使えます。
- **サウンド通知** - 鳴らす価値のある場面だけ、しかも見ていないときだけ。
- **統計** - 時間、習慣、実績。画像にして共有できます。
- **十言語** - 既定では IDE の言語に従います。
- **未保存のバッファ**はターンの前に書き出され、エージェントが変更したファイルはすぐに読み
  直されます。
- **エディタのタブではなく、サイドパネル**、ウィンドウのどの端にも置けます。数字キーで選択肢
  を選び、Shift+Tab でモードを切り替え、Escape でターンを止められます。

## プライバシーと透明性

- **すべて自分のマシンで動く。** 間にプロキシも、こちらのサーバーもありません。Codex への
  サインインは CLI のもので、プラグインがそれをどこかに送ることも、ディスクの API キーを探し
  回ることもありません。
- **許可なく何も送られません。** アカウント不要、裏での分析もありません。匿名の利用統計は、
  一度だけ尋ねるカードで「許可」を押すまでオフです。送るのは回数だけで、コード、メッセージ、
  ファイル名は決して送りません。統計とリモートアクセスがオフなら、外に出るのはご自身で書いて
  送るフィードバックだけで、送信前にボタン一つで正確な内容を確認できます。
- **あなたのルールは、あなたのものであり続ける。** Codex はあなたの設定、自身のサンドボックス、
  自身の承認ポリシーを適用します。画面に出ているモードは、そのスレッドが実際に動いている
  ポリシーそのものであり、プラグインがそれより緩いモードでスレッドを始めることは決してあり
  ません。
- **ソースは公開**（GitHub、Elastic License 2.0）。マシンから出る可能性のあるものは
  [プライバシーポリシー](https://github.com/crmapache/amazing-codex/blob/main/PRIVACY.md)にすべて
  挙げてあります。

## 動作環境

インストール済みでサインインした Codex CLI（`npm install -g @openai/codex`）と、2026.1 以降の
JetBrains IDE（Android Studio を含む）。Android Studio には内蔵ブラウザがないため、IDE が
JetBrains のブラウザプラグインを本プラグインと一緒に入れるか尋ねます。
