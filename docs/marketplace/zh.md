# Amazing Codex GUI

**把 OpenAI Codex 变成 JetBrains IDE 里的聊天面板。** 用卡片代替终端里的滚动输出，用手指指向文件
代替手敲路径，代码就在旁边。

它驱动的正是你机器上已装好的 Codex CLI，所以你的 ChatGPT 登录或 API 密钥、模型、配置、MCP
服务器、技能和自定义提示词都原样跟过来。没有中间代理，也不需要注册我们的账号。

## 为什么选它

- **一套工作流程，写一次，以后都由它替你跑。** 场景功能：几张卡片，每张卡片背后都是一次独立的 Codex 会话，
  负责实现、评审、修复或跑测试，这些步骤分成几个阶段，阶段可以循环不止一次，由一条主线负责串联它们，并判断每一步查到了什么。
  可以点一下按钮只跑一次，也可以同时对三个工单跑三次，或者设定在每个工作日的上午九点自动运行，并提前把它会问的问题答好。
  用一句话描述这套流程，Codex 就会读懂项目，把表单写出来。
- **整个面板都能在手机上用，而不只是一个「同意」按钮。** 可以回答权限请求或计划、打开一个已经关闭的项目、读昨天的对话、
  分叉、切换模型和思考强度、切换账号、看着一次场景运行并在它卡住时解锁继续。默认关闭，扫码配对，
  全程端到端加密，经手的中转服务器读不到一个字，一键即可撤销。
- **多个 Codex 账号，一键切换。** 工作账号和个人账号可以在同一台机器上共存，谁都不用登出：
  各自登录各自的账号，历史记录、配置和技能则是共用的。每一行都显示这个账号还剩多少额度，
  点 Select 就能把所有打开的对话都转移到它上面。
- **跨越项目里的每一次对话搜索。** 支持前缀、拼写错误、词干、引号里的完整短语；可以只搜当前对话，也可以搜全部对话，
  点一下就能跳到消息所在的那次对话里。如果几个关键词说不清楚，描述一下你要找什么，Codex 会替你读完所有对话。
- **它做的每件事都摆在屏幕上。** 每一条命令连同耗时，每一次编辑都是带着真实行号、可以展开的差异，
  逐条勾掉的计划，网页搜索，MCP 工具调用，还有这一轮花了多少 token。请求被重试或者额度用完时，出现的是一张写明原因和倒计时的卡片，
  而不是莫名其妙的沉默。
- **没有人替你回答，也不会丢掉任何东西。** 权限请求、计划或提问会一直等你，要多久等多久，既没有超时，也不会自动继续。
  折叠面板或者切到别的项目，对话依然在继续；一轮进行中途写下的消息，会被并入这一轮，或者留在 IDE 保管的队列里等着。
- **也支持 Android Studio**，以及 2026.1 起的所有 JetBrains IDE。

## 面板里还有什么

- **指向文件，而不是敲出路径。** 把文件拖进来、输入 `@` 挑选它、粘贴一张截图或一段很长的日志，每一样都会变成一枚不会打错的胶囊。
- **发送代码，带着它的地址。** 选中几行代码，选择「Send to Amazing Codex GUI」，
  智能体读到的是这几行周围真实的文件，而不是一段没有来龙去脉的片段。
- **路径能直接打开文件。** 对话里任何地方出现的路径，无论是卡片标题、回答、报错，还是你自己发的消息，都会在编辑器里打开对应文件，
  并跳到它标出的那一行；如果这个路径指向一次编辑，打开的就是那次编辑本身。
- **抓住回答里的任意一部分。** 把它引用到下一条消息里，从那个精确位置分叉出对话，最多可以把三条消息置顶在对话上方，
  或者把已经发送的消息收回输入框，改好后重新发送。
- **模型、思考强度和权限模式可以在对话中途切换**，各标签页互不影响，无需重启任何东西：每次都问、自动、
  只读、计划，或者完全放行。思考强度菜单只会给出当前模型真正拥有的那几档。
- **MCP 服务器和插件**都有各自专属的界面：哪个服务器已经启动，哪个还需要登录，哪个挂了、为什么挂了。
- **历史**：本项目过去的对话，包括在终端里开始的那些，从末尾打开，按需向前翻页加载更早的内容。
- **Codex 自带的命令**：`/compact`、`/review`、`/init`、`/new`，还有你自己的自定义提示词和技能，
  都会出现在输入框的建议里。
- **旁路提问**：用 `/side` 或 `/btw`，在 Codex 工作时提问，答案出现在输入框上方的卡片里，
  对话本身看不到它。
- **Codex 自身的设置**有单独的界面（`/config`）：查看 config.toml 写了什么、每个值来自
  哪里，一键信任项目。
- **`!` 在你自己的 shell 里运行命令**，输出会随你的下一条消息一起发送，不占用一轮对话，也不会弹出权限请求。
- **改写提示词**：星形按钮用一次独立的运行改写你的草稿，不消耗对话本身的上下文，一个按钮就能把你原本的话找回来。
- **语音输入**：用你自己的 Deepgram 密钥，按住热键即可开始，在编辑器里也能用。
- **声音提醒**：值得出声的时刻才响，而且只在你没有正看着的时候才响。
- **统计**：小时数、习惯与成就，可以做成图片分享出去。
- **十种语言**，默认跟随你的 IDE。
- **你未保存的编辑器缓冲区**会在一轮开始前写入磁盘，智能体改过的文件也会被 IDE 立刻重新读取。
- **是侧边面板，不是编辑器标签页**，可以停靠在窗口的任意一边；数字键可以选择选项，Shift+Tab 循环切换权限模式，
  Escape 用来停止这一轮。

## 隐私与透明

- **一切都在你自己的机器上运行。** 没有中间代理，中间也没有我们的服务器。Codex 的登录状态属于
  CLI，插件从不把它发送到任何地方，也不会在你的磁盘上翻找 API 密钥。
- **未经你同意，什么都不会发出。** 无需账号，也没有暗中的分析。匿名使用统计默认关闭，直到你
  在只询问一次的卡片上点击“允许”：只发送计数，绝不发送代码、消息或文件名。统计和远程访问
  都关闭时，唯一离开电脑的只有你自己写并发送的反馈，而且一个按钮会先显示它的确切内容。
- **你的规则仍然是你的规则。** Codex 应用的是你自己的配置、它自己的沙箱和它自己的权限策略；
  屏幕上显示的模式，就是这一轮真正在用的策略，插件绝不会用比屏幕上更宽松的模式启动一轮对话。
- **源码公开**在 GitHub 上，采用 Elastic License 2.0，
  [隐私政策](https://github.com/crmapache/amazing-codex/blob/main/PRIVACY.md)列出了一切可能离开这台机器的东西。

## 环境要求

已安装并登录的 Codex CLI（`npm install -g @openai/codex`），以及 2026.1 起的任意 JetBrains IDE，
包括 Android Studio。Android Studio 自身不带内嵌浏览器，因此 IDE 会提示把 JetBrains 的浏览器插件
和本插件一起装上。
