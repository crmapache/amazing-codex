# Догоняем оригинал: ACC 0.13.46 - 0.13.64

Перенос 2026-11-25, ветка `catch-up/acc-0.13.64`, версия форка 0.3.2. Предыдущий шаг - `docs/catch-up-acc-0.13.45.md`.

## Как переносилось

- Точка: форк содержал ACC до 0.13.45 (перенос 0.3.1). Диапазон оригинала `6a781c3..2be8416`: 45 коммитов (26
  содержательных), 291 файл, ~13.4 тыс. строк добавлено и ~6.4 тыс. убрано.
- Трёхстороннее слияние `git merge-file` с тем же переименованием, что в прошлые разы (`amazingclaudecode` ->
  `amazingcodex`, `claude/` -> `codex/`, `Claude*` -> `Codex*`, кроме `ClaudeCode`, `ClaudeModels`,
  `ClaudeProjectConfig`): 138 файлов слито чисто, 91 с конфликтами, 40 новых, 14 удалённых, 8 пропущено
  (`usage-service/` живёт в оригинале, `SettingSources.tsx` в форке нет).
- **Чисто слитые файлы Kotlin проверялись так же, как конфликтные**: слияние без конфликта приносило логику Claude
  Code туда, где у форка своя (аккаунты, история, запуск, сессия, настройки, разовые запуски). Такие файлы
  возвращены к форку, а нужное перенесено руками: `CodexSession`, `CodexSessions`, `CodexLaunch`, `CodexHistory`,
  `CodexConfig`, `CodexCli`, `CodexPlugin`, `CodexExecutable`, `CodexLogin`, `ProjectAuth`, `CodexControlPing`,
  `PromptImprover`, `ScenarioAuthor`, `AiSearch`, `TranscriptText`, весь `codex/accounts`, `CodexTokenUsage`.
- Правила `.claude/rules`: в конфликтах оставлен текст форка, разделы оригинала о новых фичах дописаны под Codex
  (terminal-handoff, prompt-suggestions, changed-files, history, stats, accounts, feedback).
- Сервис статистики в оригинале (`usage-service/`, общий): терминал, экран шрифта и настройка шрифта стали общими
  для обоих плагинов, `feedback_sent` у форка снят - его тест `codexFork.test.ts` сверяет списки с форком.

## Что под Codex сделано своим

- **Разговор в терминале** (0.13.64). `codex resume <тред> --no-daemon` с выбором вкладки и её аккаунтом;
  `--no-daemon`, чтобы тред держал процесс терминала, а не общий фоновый сервер Codex. Хвост после возврата - по
  ходам Codex (`thread/turns/list`), якорь - id предмета из журнала вкладки. Реестра живых процессов у Codex нет,
  поэтому `ConversationHolders` не перенесён: чужой писатель узнаётся по отказу Codex на открытии, и лента говорит
  это словами.
- **Подсказка следующего сообщения** (0.13.50). Вместо флага CLI - `thread/prediction/request` Codex, ответ
  `thread/prediction/updated` переводится в строку `prompt_suggestion`. Codex 0.163 отвечает «not implemented yet»,
  и этот Codex больше не спрашивается (по отпечатку файла); заработает сама с Codex, где догадка есть.
- **Все файлы хода по диску** (0.13.51). След хода (`TurnFootprint`, снимки git) встроен в хаб форка и объединяется
  со своей сверкой патчей (`TurnFiles`) в одно событие `files_settled`. Правка `remove` - в модели отката форка.
- **Удаление и переименование из истории** (0.13.57, 0.13.62): `thread/delete` (насовсем, с тредами агентов; слова
  подтверждения честные во всех языках) и `thread/name/set` через общий процесс каталога.
- **Токены по проектам** (0.13.50): папка запроса - `cwd` из `session_meta`/`turn_context` файла треда.
- **«Sign in again»** (0.13.49): `codex login` в ящике строки, опрос ящика, отмена.
- **Отзывы** (0.13.47): форма убрана, как в оригинале. Форк слал на тот же `feedback.mzpizote.com`, а тот после
  выключения отвечал строкой про Ko-fi - перенос закрыл и это. Адрес из старой формы стирается при первом чтении
  настроек.
- Строка `/status`: имя поля ответа - `command`, как у оригинала (было `resume`), функции строки `codex resume`
  остались своими (`feed/sessionInfo.ts`).
- Остальное - общий код панели: меню карточек, кнопки шапки, «+» после последней вкладки, шрифт панели, отказ от
  обучения Deepgram, цитата выделением и агенты в работе на телефоне, многострочная команда в карточке, каретка для
  цитаты, падение браузера и страницы, «custom» вместо модели, исправления vite/vitest и `source-map-js` 1.2.2.

## Что не перенесено

- Фоновые списки плагинов без входа (`noSignIn`): `codex plugin list` без входа не видит удалённых плагинов (замер:
  3.3 КБ против 11.3 КБ). Строка обычного входа, слетевшего сам собой (`keepsSignedOutDefault`).
- Уборка клонов маркетплейсов после вопроса о расходе (`ProbeLeftovers`, семя плагинов): у форка вопрос идёт в
  окружении ящика без своей папки конфига.
- Имя папки проекта по правилу CLI: у Codex папок проектов нет.
- `ConversationHolders`, общая проверка флагов разовых запусков (`addIfSupported`), настройка подсказок в «How
  Claude works». Подробно - CLAUDE.md, «Что не перенесено и почему».

## Замеры на Codex 0.163 (2026-11-25)

- `thread/prediction/request` есть в списке методов (экспериментальный), ответ - ошибка -32601 «thread/prediction/
  request is not implemented yet». В открытом коде app-server он отвечает `method_not_found`. Рядом есть
  `thread/fork.experimentalPredictionMode` (эфемерный форк для догадок).
- `thread/delete` удаляет тред и треды его агентов из записи и с диска (код `thread_delete.rs`), шлёт
  `thread/deleted`.
- `codex resume` по умолчанию подключается к общему фоновому серверу, если тот запущен; `--no-daemon` - свой
  процесс. `~/.codex/app-server-daemon/loaded-threads.json` - список для перезапуска демона, не реестр писателей.
- `codex plugin list --json`: со входом 11.3 КБ, из ящика со ссылками на всё, кроме `auth.json`, - 3.3 КБ.
- Файл треда: `session_meta.payload.cwd` в первой строке, `turn_context.payload.cwd` в каждом ходе.
